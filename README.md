# stock-analyzer

基于**历史形态相似度匹配**的股票短线统计预测工具集。核心思路：把最近的行情切片（近10日归一化收益形态），在标的全历史中寻找最相似的样本窗口，用这些样本的后续走势做概率推算，并结合**量能、大盘、板块指数**对样本进行加权筛选。

---

## 文件说明

| 文件 | 说明 |

## 功能（GUI 版）

- **K线主图**：MA5/10/20/30/60、买卖点标记（B/S）、次日(T+1)预测K线
- **副图**：成交量（含5日均量）、MACD / KDJ / RSI 可切换
- **十字光标**：三图联动，右侧价格轴 + 底部日期轴对齐显示
- **预测**：
  - 今日(T) 收盘/最高/最低 P10~P90 分位区间（锚定今开）
  - 次日(T+1) 预测K线
  - 相似历史参考日期列表
- **买卖点规则**：MACD 金叉死叉、KDJ 高低位交叉、RSI 超买超卖、放量穿越 MA20、历史相似形态次日涨跌分布
- **多维筛选**：形态匹配评分 = 价格形态 + 量能状态(放/平/缩量) + 大盘(上证)当日涨跌差 + 板块指数涨跌差
- **自选池**：左侧列表，双击分析，持久化到 ini
- **五大指数条**：上证 / 深成 / 创业板 / 科创50 / 北证50，30秒自动刷新
- **AI 分析**（DeepSeek）：整合技术面、量价、大盘板块环境与统计预测，输出操作建议；API Key 仅保存在本地 ini
- **个性化设置**：暗色/亮色主题、红涨绿跌/绿涨红跌

## 使用方法

```
双击或命令行运行: python stock_gui.py
输入代码（如 002241 / 600519 / sh600519），回车或点【分析预测】
滚轮：缩放K线    悬停：OHLC + 指标值
```

## 数据与配置

- 行情源：腾讯行情接口（前复权日线）、东方财富（板块指数）
- 配置文件 `stock_gui.ini`：

```ini
[watchlist]
codes = sz002241,sh600519
[ui]
last = sz000725
theme = dark        ; dark / light
updown = red_up     ; red_up / green_up
[deepseek]
api_key = sk-xxxx   ; 仅存本地
```
