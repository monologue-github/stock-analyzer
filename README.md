# stock-analyzer

基于**历史形态相似度匹配 + 多维融合**的股票短线统计预测工具集。v2.0 核心升级：三级样本池加权融合、筹码分布分析、多维综合评分买卖点系统。

## v2.0 算法原理

### 1. 形态匹配与样本池

**L1 自身历史**：将最近10日的归一化收益率序列作为形态切片，在标的自身600日全历史中用欧氏距离+量能距离加权匹配，取Top6最近样本。

**L2 同行业**：同行业股票的近期走势作为辅助样本池（权重0.3），捕捉板块联动效应。

**L3 同市值层**：相近市值股票的走势作为第三级样本（权重0.1），捕捉大小盘轮动规律。

三级样本按 **L1:0.6 / L2:0.3 / L3:0.1** 加权融合，用加权百分位数（P10/P25/P50/P75/P90）生成预测区间。

### 2. 量能状态与大盘环境筛选

- **量能分区**：按当日成交量/20日均量划分为「放量/平量/缩量」三个regime
- **大盘过滤**：剔除与当日上证涨跌差异>0.8pp的样本，保留市场环境相近的样本
- **板块过滤**：剔除与当日板块指数涨跌差异>1.2pp的样本
- **开盘缺口**：若上述筛选不足3个样本，改按开盘缺口±1%筛选

### 3. 筹码分布（Volume-at-Price Profile）

逐日演化计算筹码分布：
- 每根K线的成交量按高低价区间均匀摊分到价格格子
- 历史筹码按换手率衰减（换手率用量/中位量×2%启发式近似）
- 输出：平均成本、获利盘比例、90%筹码区间、支撑位/压力位（现价上下方最密集筹码峰）

### 4. 多维综合评分（买卖点核心）

每日对7个维度打分（+1/0/-1），方向切换时触发买卖信号：

| 维度 | 偏多(+1/+2) | 偏空(-1/-2) |
|------|-------------|-------------|
| MACD | DIF>DEA(+1), 金叉(+2) | DIF<DEA(-1), 死叉(-2) |
| KDJ | K>D(+1), 低位金叉(+2) | K<D(-1), 高位死叉(-2) |
| RSI6 | <30超卖(+1), 超卖回升(+2) | >70超买(-1), 超买回落(-2) |
| 量价 | 放量上涨(+1) | 放量下跌(-1) |
| MA20 | 价>MA20且MA20↑(+1) | 价<MA20且MA20↓(-1) |
| 筹码 | 贴近支撑(+1) | 贴近压力(-1) |
| 统计预测 | 上行概率≥55%(+1) | 上行概率≤45%(-1) |

**触发规则**：
- 得分≥2 且前一次信号为空头/无 → 生成 **BUY** 信号
- 得分≤-2 且前一次信号为多头/无 → 生成 **SELL** 信号
- 两次信号间隔≥5根K线（冷却期）
- 每天最多一个信号，买和卖自然配对

**综合评估**（侧栏展示）：同维度打分，输出合计分值和结论（偏多/略偏多/观望/略偏空/偏空）。

### 5. 缓存校验

- 加载本地缓存后，校验相邻日涨跌幅是否超出该股允许的涨跌幅范围（主板10%、创业板/科创板20%、北交所30%、主板ST新规10%/旧规5%）
- 留3个百分点容差吸收前复权除权分红造成的合法跳变
- 历史不足30根的新股跳过检查（上市初期无涨跌幅限制）
- 异常数据触发全量重新下载替换

## 功能（GUI 版）

- **K线主图**：MA5/10/20/30/60、筹码峰叠加（右侧横向剖面）、支撑/压力虚线、买卖点标记（B/S）、预测K线
- **副图**：成交量（含5日均量）、MACD / KDJ / RSI 可切换
- **十字光标**：三图联动，右侧价格轴 + 底部日期轴对齐显示
- **预测**：
  - 今日(T) 收盘/最高/最低 P10~P90 分位区间（锚定今开）
  - 次日(T+1) 预测K线
  - 相似历史参考日期列表
- **筹码参考**：平均成本、获利盘比例、90%筹码区间、支撑/压力位
- **综合评估**：多维打分买卖点参考（MA20/MACD/KDJ/RSI/量价/筹码/统计预测）
- **自选池**：左侧列表，双击分析，持久化到 ini
- **五大指数条**：上证 / 深成 / 创业板 / 科创50 / 北证50，30秒自动刷新
- **AI 分析**（DeepSeek）：整合技术面、量价、大盘板块环境、筹码分布与统计预测，输出操作建议；**支持多轮追问**（首轮携带完整数据上下文，追问只追加新问题，共享同一份数据，不重复拉取）
- **K线增量加载**：启动快速显示基础预测（走缓存秒开，快启动速度优先），随后**后台逐批加载同行业/同市值层样本池，预测K线边加载边更新**——样本越多，统计预测越准（大缓存提升准头）
- **缓存不自动清理**：本地缓存永远保留（可大），同市值层样本池同日共享、避免重复拉取浪费空间
- **个性化设置**：暗色/亮色主题、红涨绿跌/绿涨红跌

## 使用方法

```
双击或命令行运行: python stock_gui.py
输入代码（如 002241 / 600519 / sh600519），回车或点【分析预测】
滚轮：缩放K线    悬停：OHLC + 指标值
```

## 数据与配置

- 行情源：腾讯行情接口（前复权日线）→ 东方财富 → 网易163 → 新浪财经（多源容灾）
- 板块/指数：东方财富
- 配置文件 `stock_gui.ini`：

```ini
[watchlist]
codes = sz002241,sh600519
[ui]
last = sz000725
theme = dark        ; dark / light
updown = red_up     ; red_up / green_up
[deepseek]
api_key = sk-xxxx   ; 仅存本地
```
