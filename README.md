# v4.0.1 变更（2026-09-06）

1. **成本口径**：回测去掉佣金/印花税（记 0），只保留滑点 0.1%/边——更贴近实际免五低佣账户；`research/v4_report.json` 的 `meta.cost` 如实记录。
2. **退出策略改为 hybrid 混合（新默认）**：Q10 棘轮止损（只收紧）+ **移动止盈棘轮**（浮盈触发后随最高价上移）+ p_up 信号退出；**移除 Q75 硬目标位退出**（v4.0 实测它把平均持仓压到 4.7 天，是三档全负的主因）。消融新增 `Exit: Dist(v4.0)`（复现旧纯分布退出）、`Hybrid - Trailing`、`Hybrid - Q10Stop` 三变体。60 只抽样实测：平均持仓 5.8~7.9 天（旧 4.7），激进档年化转正；**全量重跑待办**。
3. **荐股优化**（依据 v3.3/v4 全A实证）：RSI 改动量口径（超卖反弹假设不成立，IC -0.098——超卖不加分、强势加分）；新增 **MA20/60 趋势维度**（IC 0.228）与 **L1 形态上行概率维度**（IC 0.265），权重 1.2。
4. 修复 CLI 在 GBK 控制台打印 ⚠️ 崩溃（`sys.stdout.reconfigure(errors="replace")`）；删除被矩阵版覆盖的旧版逐股组合回测死代码（回测口径唯一实现）。

# v4.0 架构

v4.0 在 v3.3 的 L1/L2/L3 形态匹配核心之上，加入一套**个股自适应 ML 管线**（全部内嵌于单文件 `stock_gui.py`，CLI 由 `build_cli.py` 自动生成，仍是单文件）：

```
全A缓存日K ──> 13因子矩阵（逐日，仅用T日及以前数据）
                 │  L1形态up_prob/相似样本收益 + MA20/60乖离 + 5/10/20日收益
                 │  + RSI14 + ATR% + 20日波动 + 量变 + 大盘5日 + 行业5日
                 ▼
   Walk-Forward 时序验证（扩展窗，40日折，折间不重叠，~9折/股）
                 │  每折内（只用训练段）：
                 │   ① Horizon 自适应：训练段内层75/25切分，T+1/T+5/T+10 选优
                 │   ② Lasso：标准化因子 → 稀疏权重（全零则退回 IC×稳定性 加权）
                 │   ③ Logistic(L2)：p_up 方向概率
                 │   ④ LightGBM：非线性收益预测（浅树/强正则/先验超参）
                 │   ⑤ Quantile Regression：Q10/Q25/Q50/Q75/Q90 收益分布
                 ▼
   同一套模型输出（p_up / ml / Q10·Q50·Q75 / 自适应分数）
                 │
        ┌────────┼────────┐
        ▼        ▼        ▼
      保守      平衡      激进        ← 三档=同一模型的决策层参数，不分别训练
   （入场阈值/仓位/最大持仓数/退出置信度不同）
```

- **预测分布驱动退出**：v4.0.1 起默认 **hybrid 混合退出** = Q10 棘轮止损（只收紧）+ 移动止盈棘轮 + p_up 信号退出（Q75 硬目标退出已移除，`exit_mode="dist"` 可复现旧行为）；ATR止损/移动止盈（v3.3 风控）**保留为对照退出与极端行情防火墙**。
- **消融实验**：12 个变体（逐组件移除 + 关键组合），全部跑在**同一套 Walk-Forward 预测输出**上（决策层消融），只换入场/退出规则，公平比较。
- **统一回测口径**：同初始资金（100万）、同成本（滑点0.1%/佣金0.03%/印花税0.1%卖出）、同成交时点（信号日收盘）、涨停禁买/跌停顺延、停牌持仓顺延、期末强平。

# Baseline vs v4.0

**直接结论：v4.0 Full 在 1000 交易日全A回测中再次没有战胜 v3.3 Baseline，且差距扩大。**

| 口径 | v3.3 Baseline（稳健） | v4.0 Full（平衡） |
|---|---|---|
| 年化 | **+8.4%** | -15.0% |
| 最大回撤 | **-21.7%** | -44.9% |
| Calmar | **0.39** | -0.33 |
| Sharpe | **0.46** | -0.92 |
| 交易数 | 159 | 396 |
| 平均持仓 | 10.8 日 | 4.7 日 |

**为什么信号更好、组合更差（如实归因）**：
1. v4 的分布退出（Q10棘轮 + Q75目标 + p_up 信号退出）把平均持仓压到 4.7 天，每笔往返成本 ≈0.36%；而样本外 IC 只有 ~0.02 量级，**成本与执行损耗完全吞噬了信号优势**。
2. v3.3 的 ATR/移动止盈持仓 10.8 天、交易数不到一半，成本损耗小得多。
3. 消融直接证明了这一点：把 v4 的退出退回 ATR 对照（"Full - DistributionExit"），同样的入场只剩 10 笔交易、年化 +49%——**退出结构是 v4 当前最大的负贡献项**（但仅 10 笔，小样本，见消融表）。

**哪个组件真的贡献了性能（平衡档，1.3年窗口）：**

- **Adaptive（Lasso 自适应过滤）：负贡献**——移除后年化 -15.0%→+2.6%、回撤 -44.9%→-26.2%。自适应入场与紧退出叠加时显著放大了亏损。它单独使用时（Adaptive 策略行）年化为正但回撤 -53%~-65%、交易仅 20~38 笔。
- **Logistic：正贡献**——移除后 -8.7%（好于 Full 但差于 -Adaptive）。

- 所有正年化变体（+48%~+49%）均为 **≤17 笔交易**，由个别持仓主导，**不作为有效证据**。

# 风险分析

- **成本敏感（核心风险）**：Full 档平均持仓 4.3~4.7 天，单边成本 0.13%~0.23%，年化被成本吃掉 ~10+ 个百分点；降频/拉长持仓是首要改进方向。
- **集中度**：Adaptive 档单仓 12~33% 但同时最多 4~10 仓、持仓 29~66 天——收益依赖少数长持仓（胜率仅 5~18%、盈亏比 3.9~6.8），单票黑天鹅足以摧毁全年。
- **市场段单一**：组合窗口 408 个交易日（2024-12 → 2026-08），未覆盖完整牛熊。
- **幸存者偏差**：组合回测要求测试段结束接近最新日（5077/5411）；336 只停牌、421 只退市股只参与 IC 统计。
- **小样本陷阱**：Adaptive 三档与全部正年化消融变体的交易数都 ≤38 笔，未做显著性检验前一律视为噪声。

# 数据与回测方法

- 数据：腾讯/东财/网易/新浪多源前复权日K，本地 SQLite 缓存（`stock_cache.db`，808万根）；回填 `--backfill`（断点续传）+ 清洗 `--clean`（异常2根删除、除权残留重拉972只、退市421只、停牌336只）；离线包见文首「离线缓存下载」。
- 因子（13个，全部 T 日及以前）：L1形态up_prob、L1相似样本收益（逐日自身历史匹配，与 v3.3 `_sig_l1_pattern` 同口径）；MA20/60 乖离；5/10/20 日收益；RSI14；ATR14/Close；20日波动率；量变(5/20)；大盘5日收益；行业5日收益（市场/行业等权日收益由缓存一次性预计算）。
- 标签：`Close[T+H]/Close[T]-1`，H∈{1,5,10}，仅作训练目标。
- Walk-Forward：扩展窗，折 40 交易日，首折前训练 ≥180 日，折间不重叠；每股 ~9 折（360 测试日）。
- 训练段内完成：标准化（Scaler 只 fit 训练段）、Lasso 筛选（α=0.005，全零退回 IC×稳定性加权）、Horizon 选择（内层 75/25 切分）、全部模型拟合。
- LightGBM 超参（先验固定）：`num_leaves=15, max_depth=4, lr=0.05, n_estimators=200, min_child_samples=40, subsample=0.8, colsample=0.8, reg_lambda=1.0`。
- 组合模拟：现金+持仓逐日 mark-to-market；v4.0：买入=收盘×(1+滑点)(1+佣金)，卖出=成交价×(1-滑点)(1-佣金-印花税)；**v4.0.1：佣金/印花税记 0**；一手 100 股整数化；期末强平。

# 数据泄漏检查

✅ 特征仅用 T 日及以前数据（形态匹配样本窗口结束于 T-20 之前）
✅ 标签仅作训练目标，不进入特征
✅ StandardScaler 仅在训练段 fit

# 当前结论

1. **v4.0 Full 没有战胜 v3.3 Baseline**（年化 -15.0% vs +8.4%，回撤 -44.9% vs -21.7%），三档全负。
2. **信号质量确有提升**：LightGBM/Q50/Logistic 样本外 IC 0.015~0.022（190万样本、显著为正），高于 v3.3 的 L1 形态（0.004）与多维评分（-0.005）——但**组合转化失败**，瓶颈在退出结构与交易成本，不在信号。
3. **消融结论**：Adaptive 过滤为负贡献（移除后 +2.6%）；Logistic/LightGBM 为正贡献但仍不足；Horizon 自适应无差异；Quantile 退出无法判定（10笔）。
4. **LightGBM 过拟合标记为真**（0.642 vs 0.022）；其相对线性模型的优势有限。
5. **Adaptive 单独使用年化 +27%~+63% 但不可信**：胜率 5~18%、回撤 -53%~-65%、≤38 笔交易，是集中持仓的小样本运气。
6. **下一步最有价值的方向**（按优先级）：① 把分布退出改成"棘轮止损 + 移动止盈"混合、拉长持仓；② 按信号强度分档降频（只在 IC 更高的 T+10 周期交易）；③ LightGBM 改用全市场横截面训练而非单股训练，从根本上解决过拟合。

# v3.x 算法原理（保留，构成 v4 因子与基线）

## 1. 形态匹配与样本池

**L1 自身历史**：将最近20日的归一化收益率序列作为形态切片，在标的自身全历史中用欧氏距离+量能距离加权匹配，取Top-K样本。
**L2 同行业** / **L3 同市值层**：辅助样本池（可关），捕捉板块联动与大小盘轮动。
三级样本加权融合，用加权百分位数（P10~P90）生成预测区间（校准系数 1.3/1.4）。

## 2. 量能状态与大盘/板块环境筛选

量能分区（放量/平量/缩量）、大盘过滤（涨跌差>0.8pp剔除）、板块过滤（>1.2pp剔除）、开盘缺口兜底。

## 3. 筹码分布（Volume-at-Price Profile）

逐日演化：成交量按高低价摊分到价格格子、按换手率衰减；输出平均成本、获利盘、90%筹码区间、支撑/压力位。

## 4. 多维综合评分（v3.3 买卖点核心）

MACD/KDJ/RSI6/量价/MA20/筹码/统计预测/ADX 八维打分，≥+2 触发 BUY、≤-2 触发 SELL，冷却 5 根K线。v3.3 消融弹窗：训练75%选型/验证25%只报告，三档（保守/稳健/激进）牛熊分段评分，缓存5日。

## 5. 缓存校验

相邻日涨跌幅超限校验（主板10%、创业/科创20%、北交所30%，留3pp容差），异常触发重拉。
