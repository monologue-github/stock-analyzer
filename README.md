# stock-analyzer

基于**历史形态相似度匹配 + 多维融合 + Walk-Forward 自适应 ML + 量化回测**的 A 股短线统计研究工具。

> **个人研究项目，输出仅供历史统计参考，不构成投资建议。**
> 欢迎交流（联系方式见网站底部）。

### L1 形态匹配特征消融（全缓存 · 步长 1 · 2026-09-12）

> 脚本：`backtest_ablation.py`（已 numpy 向量化加速，约 2.6 小时跑完全量）  
> 协议：每股单独 Walk-Forward，只用 t 及以前数据；样本窗口 j ∈ [W, t+1-W)；标签 = close[j+1]/close[j]-1；预测 = 加权分位 P50；实际 = close[t+1]/close[t]-1。  
> 股票池：全缓存非 ETF 股票 **5518 只**，评估步长 **1**，总样本 **~767 万**。

| 配置 | 方向命中 | 上行命中 | IC | MAE |
|---|---|---|---|---|
| base（全部特征+指数加权+衰减） | 50.1% | 50.1% | **-0.0047** | 2.405% |
| -struct（去K线结构） | 50.0% | 50.0% | -0.0063 | 2.405% |
| -vola（去波动率） | 50.1% | 50.1% | -0.0055 | 2.405% |
| -rsi（去RSI） | 50.1% | 50.1% | -0.0054 | 2.406% |
| -volchg（去量变） | 50.1% | 50.1% | -0.0047 | 2.401% |
| -weekly（去周线） | 50.1% | 50.1% | -0.0048 | 2.406% |
| px_only（纯形态=旧版） | 50.0% | 50.0% | -0.0060 | 2.407% |
| -decay（去时间衰减） | 50.2% | 50.2% | -0.0047 | **2.385%** |
| -simw（去相似度加权） | 50.2% | 50.2% | -0.0055 | **2.352%** |

**结论**：
1. **所有配置 IC 均在 0 附近且为负**：在 767 万样本、5518 只股票的规模下，L1 形态匹配本身**无统计显著的方向预测力**。
2. **去相似度加权（simw）降低 MAE**：从 2.405% → 2.352%，说明等权后点估计更稳定，与历史小样本结论一致。
3. **去时间衰减也降低 MAE**：2.405% → 2.385%，但幅度很小。
4. 扩展特征（struct/vola/rsi/volchg/weekly）对方向命中率无实质提升，与满功率裁决结论一致：这些特征在等权机制下从"拖后腿"变成"无害"。

## 核心结论


1. **信号 IC ≠ 组合收益**：LightGBM 样本外 IC 为正（0.022），但 Full v4 三档仍接近成本线或略负；选股信号只是组合收益的必要条件，退出结构、持仓周期、交易成本共同定价最终收益。
2. **退出结构是最大杠杆**：旧 v4.0.1 hybrid（移动止盈 1.02/回落 0.94）在正确口径下年化 -16.0%，比纯分布退出差约 13pp；默认退出已改回 **dist 分布退出**。
3. **最佳可交易结构**：
   - **Rot-T10only**：T+10 信号 + 板块轮动门槛（行业前 30%）+ 分布退出，年化 **+15.6% / -16.1% / Calmar 0.97**。
   - **T10only 无轮动版**：年化 **+7.8% / -12.7% / Calmar 0.61**。
   - 两者均待滚动窗口/分年度复核后升级为正式默认档。
4. **板块轮动有效但只认强势**：行业 5 日收益作为**门槛**（非线性因子）能显著改善结果；Top50 / 非强势行业反而有害。
5. **升档再入场 vs 冷却**：Reentry-Off（关闭升档再入场）为 +3.1%，说明原"升档再入场"在 dist 退出下无额外增益；但 T10only 结构下保留再入场与关闭结果相同。
6. **成本敏感**：在平均持仓 5 日、滑点 0.1%/边、无佣金的口径下，Full v4 已贴近成本线；任何额外交易成本都会显著拉低表现。

## 每只股票自动策略消融（v3.3 风格 · 全 A 实证）

> 脚本：`backtest_strategy_ablation.py`  
> 运行时间：2026-09-12，全 A 非 ETF 股票 **5518 只**，耗时 **690 秒**  
> 口径：与 GUI「工具 → 多算法消融选策略」完全一致。

对每只股票单独执行：
1. 取近 **1000 交易日**；
2. 生成候选信号：MACD 金叉死叉 / KDJ 低位金叉高位死叉 / RSI 超卖回升超买回落 / 布林带下轨回升上轨回落 / MA20 上穿下穿 MA60 / L1 形态上行概率 / 多维评分 × 3 档风险；
3. 训练集（前 75%）选型，验证集（后 25%）只报告，**验证集绝不参与选择**；
4. 按保守（最小回撤）、稳健（收益回撤比最大）、激进（最大年化）三档目标，分别为该股选出最优策略；
5. 两层输出：
   - `research/strategy_ablation_per_stock.json`：每只股票的三档最优策略、全部候选策略的训练/验证指标、牛熊分段收益；
   - `research/strategy_ablation_summary.json`：全市场聚合统计，包括各算法/档位选中占比、训练/验证集年化/回撤/胜率/交易数中位数。

### 运行方式

```bash
# 全 A 股（5518 只左右）
python backtest_strategy_ablation.py

# 测试前 N 只
python backtest_strategy_ablation.py --limit 100 --workers 4
```

### 关键发现

1. **训练集 ≠ 验证集**：稳健档训练年化中位 +11.3%，验证年化中位 -2.0%；激进档训练 +14.5%，验证 -3.2%——说明按单股历史选出的"最优策略"样本外普遍衰减，存在过拟合/选择偏差。
2. **保守档训练/验证最接近**：训练 -10.9% vs 验证 -6.9%，但绝对收益为负。
3. **算法偏好因档位而异**：保守档偏爱 KDJ/L1（低频次、偏反转），稳健档偏爱 MA 趋势/RSI（趋势跟踪），激进档偏爱布林带/RSI（高波动）。
4. **牛熊分段**：稳健/激进档在牛市段训练年化显著为正（+16.4% / +24.0%），熊市段接近 0 或负；说明收益主要来自牛市环境。

### 优化点

- **多进程并行**：`ProcessPoolExecutor`，默认 `min(8, CPU 核心数)`；
- **指数 regime 全市场共享**：上证指数 `sh000001` 只加载一次，所有股票共用；
- **单文件函数调用**：直接复用 `stock_gui.py` 的 `_sig_*` / `_composite_signals` / `_bt_events`，保证口径与 GUI 完全一致；
- **去除 GUI/tkinter 依赖**：纯 CLI，适合服务器后台跑批。

## 数据与方法

### 数据

- 行情源：腾讯 → 东方财富（4 host 轮询）→ 网易 163 CSV → 新浪财经 JSON，多源容灾。
- 缓存：本地 SQLite `stock_cache.db`，WAL 模式，增量回填，负缓存 1 小时。
- 清洗：结构异常删除、除权残留整只重拉、退市登记、停牌报告、价格粘性检测。

### 因子（13 个，全部 T 日及以前）

`l1_up` / `l1_ret`（形态匹配上行概率/相似样本收益）、`bias20` / `bias60`（MA20/60 乖离）、`ret5` / `ret10` / `ret20`、`rsi14`、`atr_pct`、`vola20`、`volchg`（量变）、`mkt5`（大盘 5 日）、`ind5`（行业 5 日）。

### Walk-Forward 训练

- 扩展窗，折长 40 交易日，预热 60 日，首折训练 ≥180 日；
- 每折内完成：标准化、Lasso 筛选（α=0.005，全零则退回 IC×稳定性加权）、Horizon 内层选择（75/25 切分）、Logistic / LightGBM / Quantile Regression 拟合；
- 折间不重叠，严格无样本外数据泄露。

### LightGBM 超参（先验固定）

```python
num_leaves=15, max_depth=4, learning_rate=0.05, n_estimators=200,
min_child_samples=40, subsample=0.8, colsample_bytree=0.8, reg_lambda=1.0
```

### 组合回测口径

- 初始资金 100 万；
- 成本：滑点 0.1%/边，佣金/印花税 0；
- 成交：信号日收盘；涨停禁买、跌停顺延卖出、停牌持仓顺延、期末强平；
- 一手 100 股整数化。

## 数据泄漏检查

- ✅ 特征仅用 T 日及以前数据（形态匹配窗口结束于 T-W 之前）
- ✅ 标签仅作训练目标，不进入特征
- ✅ StandardScaler / Lasso / Horizon 选择均只在训练段完成
