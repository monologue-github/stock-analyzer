# v4.0.1 变更（2026-09-06）

1. **成本口径**：回测去掉佣金/印花税（记 0），只保留滑点 0.1%/边——更贴近实际免五低佣账户；`research/v4_report.json` 的 `meta.cost` 如实记录。
2. **退出策略改为 hybrid 混合（新默认）**：Q10 棘轮止损（只收紧）+ **移动止盈棘轮**（浮盈触发后随最高价上移）+ p_up 信号退出；**移除 Q75 硬目标位退出**（v4.0 实测它把平均持仓压到 4.7 天，是三档全负的主因）。消融新增 `Exit: Dist(v4.0)`（复现旧纯分布退出）、`Hybrid - Trailing`、`Hybrid - Q10Stop` 三变体。60 只抽样实测：平均持仓 5.8~7.9 天（旧 4.7），激进档年化转正；**全量重跑待办**。
3. **荐股优化**（依据 v3.3/v4 全A实证）：RSI 改动量口径（超卖反弹假设不成立，IC -0.098——超卖不加分、强势加分）；新增 **MA20/60 趋势维度**（IC 0.228）与 **L1 形态上行概率维度**（IC 0.265），权重 1.2。
4. 修复 CLI 在 GBK 控制台打印 ⚠️ 崩溃（`sys.stdout.reconfigure(errors="replace")`）；删除被矩阵版覆盖的旧版逐股组合回测死代码（回测口径唯一实现）。
5. **300 只中等规模实测（v4.0.1 口径）**：同一批入场下，`Exit: Dist(v4.0)`（旧纯分布退出）年化 **-3.8%**（338 笔/持仓 4~5 天）vs Full v4 hybrid **+10.6% / 回撤 -23.8% / PF 1.32 / 持仓 8.0 天**（188 笔）——入场不变、只换退出即翻转正负，**证实退出结构是唯一命门**（本样本 v3.3 baseline 三档 -5.8%~-8.4%；样本较小，全量重跑待办）。
6. **频繁交易实验（反直觉）**：给 Full 加"平仓冷却 5 根 + 最少持仓 5 根"把 +10.6% 打到 **-3.1%**——退出后信号仍有效时的快速再入场本身是收益来源，勿硬压频率。但 **T+10-only + 冷却** 组合是低频低回撤首选：年化 +6.9%、回撤 -18.0%（全场最浅）、135 笔。两条路径保留为消融变体（`Hybrid - Cooldown5` / `Hybrid - T10only`）。
7. **预测缓存**：Walk-Forward 预测与规则/成本无关，现按（股票池+数据指纹+因子版本）签名缓存 `research/v4_preds.pkl`，命中后规则/回测迭代从 ~8.5 分钟降到 **8 秒**；数据或因子代码变化自动失效（改模型代码请递增 `_V4_CACHE_VER`），`V4_NO_CACHE=1` 强制重算。
8. **交易后升档再入场（默认开，"质量门槛替代时间门槛"）**：平仓后 8 根内，同股再入场须通过**更高一档**的完整入场阈值（保守>平衡>激进阶梯）。300 只实测：Full v4 +10.6%→**+12.2%**、回撤 -23.8%→**-21.5%**、Calmar 0.45→**0.57**、交易 188→170，各项全面改善；对比时间冷却（+10.6%→-3.1%，有害）——**用户假设被证实：频繁交易的问题不在频率，在再入场质量**。同轮证伪：Q25 紧止损（-0.2%，449 笔磨死）、慢移动止盈（-5.0%）。
9. **荐股以小博大优化**：新增爆发力（20日动量 10%~35% 强势区加分、>35% 过热减分——bias20 极端延伸 IC 为负）与量能扩张维度；**MA20/60 空头趋势一票否决闸门**（IC 0.228 最强信号）；剔除 ST。

> ⚠️ 上面第 5/6 条的 300 只数字与"hybrid 退出优于 dist"的结论，事后被证明受 highest bug 影响（当时移动止盈失效，hybrid 实为"Q10棘轮+p_up"），修正后结论反转：**dist 优于 hybrid**（见 v4.0.2 节）。升档再入场（第 8 条）在修正口径下依然成立。

# ⚠️ v4.0.2 重大修正：组合模拟 highest bug（2026-09-06 深夜）

**bug**：组合级模拟（v4.0 的矩阵版**及其之前的逐股版**）中持仓最高价 `highest` 只在入场日赋值、**从未逐日更新** → 移动止盈从未生效（锚点永远停在入场日附近）。v3.3 每股事件回测（`_bt_events`）是逐日更新的正确口径；v4.0 报告的"baseline 年化 +8.4% / 回撤 -21.7%"正是失效的移动止盈意外扛单产生的**假象**。已修复（`highest = max(highest, hi)` 逐日更新），借助预测缓存 131 秒重跑全量。

**修正后全量结论（5411 只 / 408 交易日 / 滑点 0.1%/边）**：

| 配置（平衡档除注明外） | 年化 | 最大回撤 | Calmar | 胜率 | PF | 交易 |
|---|---|---|---|---|---|---|
| **T10only（dist退出+冷却5+minhold5）** | **+7.8%** | **-12.7%** | **0.61** | **45.1%** | - | 264 |
| Full v4（dist退出+升档再入场） | -3.0% | -38.3% | -0.08 | 41.2% | 0.96 | 376 |
| Full v4（激进档） | -2.2% | -36.9% | -0.06 | 42.1% | 0.97 | 233 |
| **v3.3 真实口径 baseline（修正后）** | **-16.0%** | **-39.0%** | **-0.41** | 31.6% | 0.71 | 288 |
| Hybrid 移动止盈（v4.0.1 短命默认，已撤） | -16.0% | -39.4% | -0.41 | 27.9% | 0.67 | 355 |

**修正后的硬结论**：
1. **"v3.3 baseline +8.4%"是 bug 假象**：正确口径下 v3.3 语义 baseline = -16.0%，v4.0 时代"v3.3 赢 v4.0"的叙事整体作废。
2. **移动止盈（触发 1.02/回落 0.94）是组合级最大拖累**：同入场下 hybrid -16.0% vs 纯分布退出 -3.0%（差 13pp）。A股日频 2~3% 波动下"+2% 触发、从高点回落 6% 出局"把盈利趋势绞碎。
3. **v4.0 原设计"纯分布退出"（Q10棘轮+Q75目标+p_up）才是正确方向**：不依赖 highest 锚点、从未受 bug 影响，修正后仍是全场最优，默认退出已改回 dist。
4. **新王牌 T10only**：只交易 IC 最高的 T+10 信号 + 分布退出 + 平仓冷却 5 → +7.8% / -12.7% / Calmar 0.61 / 胜率 45.1%，全场唯一年化为正且回撤可控（⚠️ 21 变体×3 档选出的最优行，存在选择偏差，待下一段样本复核）。

**依然成立**：交易后升档再入场（hybrid 族 +6.1pp；dist 下零拦截——目标位/止损出场后信号仍有效，放行即正确）；去佣金/印花税；荐股以小博大改造；预测缓存。

**板块轮动（v4.0.2 新增，行业5日收益动量门槛，决策层不重训模型）**：

| 变体（平衡档） | 年化 | 最大回撤 | Calmar | Sharpe | 胜率 | 交易 |
|---|---|---|---|---|---|---|
| Full v4（无轮动基准） | -3.0% | -38.3% | -0.08 | -0.14 | 41.2% | 376 |
| Rot-Top30（只买行业强度前30%） | **+8.7%** | **-23.0%** | 0.38 | 0.57 | 48.3% | 377 |
| Rot-Strong（只买跑赢大盘的行业） | **+9.8%** | **-27.5%** | 0.36 | 0.65 | 48.0% | 381 |
| T10only（无轮动） | +7.8% | -12.7% | 0.61 | 0.61 | 45.1% | 264 |
| **Rot-T10only（T10 + 板块轮动）** | **+15.6%** | **-16.1%** | **0.97** | **0.94** | **49.0%** | 259 |

- 行业动量不是线性因子（ind5 单因子 IC 为负）而是**准入门槛**——价值在与选股/退出结构的交互中兑现；
- **门槛放宽到前50%即失效**（-5.7%）：轮动只认强势板块，模糊的中间地带是噪声——与 L2 行业"粒度定律"同构；
- 荐股同步加入板块维度：行业5日收益强于全行业中位数 +1、行业排名前20% 再 +1（`_picks_ind_ctx`，纯本地缓存秒级）。

**Rot-T10only 稳健性复核（`research/check_rot_t10.py`，2026-09-06）**：
- **分段判决：收益集中于段2（2025-07~2026-01：+45.4%/-6.0%），段1 -1.9%、段3 -15.5%——时段依赖强，升级正式档位为时过早**；
- 参数敏感性为平台非孤峰：rot_top 0.6/0.7/0.8 → +9.5%/+15.6%/+10.6%（0.9 转负 -7.5%）；cooldown 3/5/8 → +13.1%/+15.6%/+8.7%；
- 段3 诊断：T+10 样本外 IC 三段全正（+0.079/+0.015/+0.026），**赚钱的段2 IC 反而最低**——收益来自市场结构（板块轮动趋势段）而非信号强度变化，"信号 IC ≠ 组合收益"再次应验；轮动门槛在坏时段减亏（T10only 段3 -25.0% → RotT10 -15.5%）；
- 下一步：市场状态（regime）适配——行业动量离散度/轮动广度作择时开关，而非继续调策略参数。

**Regime 探针（行业动量离散度 `disp_rank`，v4.0.2+）**：
- 定义：行业5日收益横截面 std 的窗口内分位（0~1）——分化大=轮动富集环境，普涨普跌=轮动无意义；
- **RotT10+DispHi（仅高分化时交易）**：段2 +137.7%/-7.9%（胜率 67%）、段3 从 -15.5% 收窄到 **-2.4%**、全窗口 +11.2%/-20.5%（215 笔）；已入库正式变体 `RotT10+DispHi`；
- RotT10+DispLo（仅低分化时交易）：段3 **+4.3%** 转正；
- 结论：离散度是有效的 regime 判别器；但段1 两态皆负（T10 限制在段1 本身不适配，Fullv4 段1 +9.5%）——三态路由（高分化→RotT10 / 低分化→T10only / 其他→Fullv4）理论可行，仅 3 段证据不足以定默认，待数据积累。

# v4.0 架构

> ⚠️ 本节与下方「全 A 股回测（v4.0 实证）」「Baseline vs v4.0」「消融实验」各节为 v4.0 时代数据，组合级数字受 highest bug 影响（移动止盈失效）已失真，仅作历史存档；修正后数字见上方 v4.0.2 节。模型/因子/IC 统计（Horizon、ML 比较、预测分布、数据泄漏检查）不经过组合模拟，**不受此 bug 影响，仍然有效**。

v4.0 在 v3.3 的 L1/L2/L3 形态匹配核心之上，加入一套**个股自适应 ML 管线**（全部内嵌于单文件 `stock_gui.py`，CLI 由 `build_cli.py` 自动生成，仍是单文件）：

```
全A缓存日K ──> 13因子矩阵（逐日，仅用T日及以前数据）
                 │  L1形态up_prob/相似样本收益 + MA20/60乖离 + 5/10/20日收益
                 │  + RSI14 + ATR% + 20日波动 + 量变 + 大盘5日 + 行业5日
                 ▼
   Walk-Forward 时序验证（扩展窗，40日折，折间不重叠，~9折/股）
                 │  每折内（只用训练段）：
                 │   ① Horizon 自适应：训练段内层75/25切分，T+1/T+5/T+10 选优
                 │   ② Lasso：标准化因子 → 稀疏权重（全零则退回 IC×稳定性 加权）
                 │   ③ Logistic(L2)：p_up 方向概率
                 │   ④ LightGBM：非线性收益预测（浅树/强正则/先验超参）
                 │   ⑤ Quantile Regression：Q10/Q25/Q50/Q75/Q90 收益分布
                 ▼
   同一套模型输出（p_up / ml / Q10·Q50·Q75 / 自适应分数）
                 │
        ┌────────┼────────┐
        ▼        ▼        ▼
      保守      平衡      激进        ← 三档=同一模型的决策层参数，不分别训练
   （入场阈值/仓位/最大持仓数/退出置信度不同）
```

- **预测分布驱动退出**：v4.0.1 起默认 **hybrid 混合退出** = Q10 棘轮止损（只收紧）+ 移动止盈棘轮 + p_up 信号退出（Q75 硬目标退出已移除，`exit_mode="dist"` 可复现旧行为）；ATR止损/移动止盈（v3.3 风控）**保留为对照退出与极端行情防火墙**。
- **消融实验**：12 个变体（逐组件移除 + 关键组合），全部跑在**同一套 Walk-Forward 预测输出**上（决策层消融），只换入场/退出规则，公平比较。
- **统一回测口径**：同初始资金（100万）、同成本（滑点0.1%/佣金0.03%/印花税0.1%卖出）、同成交时点（信号日收盘）、涨停禁买/跌停顺延、停牌持仓顺延、期末强平。

# v3.3 → v4.0

| 组件 | v3.3 | v4.0 |
|---|---|---|
| 核心信号 | L1/L2/L3 形态匹配 + 多维评分 | 保留，并作为 ML 候选因子 |
| 验证方式 | 训练75%/验证25% 单次切分 | **Walk-Forward 扩展窗多折** |
| 预测目标 | 次日分布（分位区间） | **T+1/T+5/T+10 自适应 + 收益分布** |
| 模型 | 形态统计 + 规则评分 | + **Lasso / Logistic / LightGBM / Quantile** |
| 退出 | ATR止损/移动止盈 | + **Q10棘轮止损/Q75目标/p_up退出**（ATR保留为对照） |
| 风险分档 | 消融选策略三档（每档不同算法参数） | **同一套模型输出上的三档决策层** |
| 回测 | 每股事件回测，跨股中位 | + **组合级回测**（资金/成本/涨跌停/停牌统一） |
| 报告 | 消融弹窗 + v3.3 研究表 | + 本 README 统一报告 + `research/v4_report.json` |

# Baseline vs v4.0

**直接结论：v4.0 Full 在 1000 交易日全A回测中再次没有战胜 v3.3 Baseline，且差距扩大。**

| 口径 | v3.3 Baseline（稳健） | v4.0 Full（平衡） |
|---|---|---|
| 年化 | **+8.4%** | -15.0% |
| 最大回撤 | **-21.7%** | -44.9% |
| Calmar | **0.39** | -0.33 |
| Sharpe | **0.46** | -0.92 |
| 交易数 | 159 | 396 |
| 平均持仓 | 10.8 日 | 4.7 日 |

**为什么信号更好、组合更差（如实归因）**：
1. v4 的分布退出（Q10棘轮 + Q75目标 + p_up 信号退出）把平均持仓压到 4.7 天，每笔往返成本 ≈0.36%；而样本外 IC 只有 ~0.02 量级，**成本与执行损耗完全吞噬了信号优势**。
2. v3.3 的 ATR/移动止盈持仓 10.8 天、交易数不到一半，成本损耗小得多。
3. 消融直接证明了这一点：把 v4 的退出退回 ATR 对照（"Full - DistributionExit"），同样的入场只剩 10 笔交易、年化 +49%——**退出结构是 v4 当前最大的负贡献项**（但仅 10 笔，小样本，见消融表）。

**深度归因（v4.0.1 复盘，数字全部来自 `research/v4_report.json` 与消融表）**：

4. **收益结构被退出规则改写（核心机制）：盈亏比倒挂**——
   | 策略 | 胜率 | 盈亏比(avg win/avg loss) | PF(毛利/毛损) | 年化 |
   |---|---|---|---|---|
   | v3.3 Baseline·稳健 | 32.1% | **2.49** | **1.17** | **+8.4%** |
   | v4 Full·平衡 | 41.7% | 1.18 | 0.84 | -15.0% |

   分布退出把"趋势跟踪型"收益（低胜率、大盈利）硬改成"均值回归型"收益（高胜率、小盈利）：Q75 硬目标在 +几个百分点处截断盈利，Q10 棘轮与 p_up 又把浮亏单快速兑现。单笔期望 = 胜率×盈亏比 −（1−胜率）：baseline 显著为正（PF 1.17），v4 为负（PF 0.84）——**胜率更高反而更亏，问题不在选股在兑现**。
5. **持有期与信号优势周期错配**：v4 信号优势随周期单调变强（T+1 IC 0.012 → T+10 0.026），但退出结构让平均持仓只有 4.7 天——**在最强的 horizon 上拿不住**。粗算单笔毛优势 ≈ IC×前向收益σ ≈ 0.026×9% ≈ 0.23%，低于 v4.0 口径 0.36% 的往返成本；T+1 更是 ~0.03% 量级，毫无生存空间。
6. **换手×成本放大差距**：396 笔 vs 159 笔，按单仓 20% 计，全窗口成本拖累 v4 ≈ 28.5% 权益（年化 ~17pp）vs baseline ≈ 11.4%（~7pp）——三档年化差距中约一半来自换手、一半来自 PF 本身。**300 只实测已双向确认**：去佣金/印花税后单笔往返降到 0.2%；同一入场只把旧分布退出换成 hybrid，年化即从 -3.8% 翻到 +10.6%（见 v4.0.1 变更 5/6 条）。
7. **信号本就不是瓶颈（历史报告的回声）**：《消融回测与调参》§8.1 满功率裁决（n=4500，见附录 A2）早已证明 L1 形态方向预测 ≈ 掷硬币；本表中 baseline 的入场信号 IC 其实是 **-0.005（负的）**，它赚钱靠的是 MA 趋势状态 + ATR/移动止盈"让利润奔跑"的结构 + 下跌段防御价值（附录 A5：下跌段信号 -4.2% vs 持有 -21%）。**v4 把力气花在改进信号（从来不是约束项），却把退出结构改坏了（真正定价收益的部分）**——这是 v4 全项目最重要的一条教训。

# 风险分析

- **成本敏感（核心风险）**：Full 档平均持仓 4.3~4.7 天，单边成本 0.13%~0.23%，年化被成本吃掉 ~10+ 个百分点；降频/拉长持仓是首要改进方向。
- **集中度**：Adaptive 档单仓 12~33% 但同时最多 4~10 仓、持仓 29~66 天——收益依赖少数长持仓（胜率仅 5~18%、盈亏比 3.9~6.8），单票黑天鹅足以摧毁全年。
- **市场段单一**：组合窗口 408 个交易日（2024-12 → 2026-08），未覆盖完整牛熊。
- **幸存者偏差**：组合回测要求测试段结束接近最新日（5077/5411）；336 只停牌、421 只退市股只参与 IC 统计。
- **小样本陷阱**：Adaptive 三档与全部正年化消融变体的交易数都 ≤38 笔，未做显著性检验前一律视为噪声。

# 数据与回测方法

- 数据：腾讯/东财/网易/新浪多源前复权日K，本地 SQLite 缓存（`stock_cache.db`，808万根）；回填 `--backfill`（断点续传）+ 清洗 `--clean`（异常2根删除、除权残留重拉972只、退市421只、停牌336只）；离线包见文首「离线缓存下载」。
- 因子（13个，全部 T 日及以前）：L1形态up_prob、L1相似样本收益（逐日自身历史匹配，与 v3.3 `_sig_l1_pattern` 同口径）；MA20/60 乖离；5/10/20 日收益；RSI14；ATR14/Close；20日波动率；量变(5/20)；大盘5日收益；行业5日收益（市场/行业等权日收益由缓存一次性预计算）。
- 标签：`Close[T+H]/Close[T]-1`，H∈{1,5,10}，仅作训练目标。
- Walk-Forward：扩展窗，折 40 交易日，首折前训练 ≥180 日，折间不重叠；每股 ~9 折（360 测试日）。
- 训练段内完成：标准化（Scaler 只 fit 训练段）、Lasso 筛选（α=0.005，全零退回 IC×稳定性加权）、Horizon 选择（内层 75/25 切分）、全部模型拟合。
- LightGBM 超参（先验固定）：`num_leaves=15, max_depth=4, lr=0.05, n_estimators=200, min_child_samples=40, subsample=0.8, colsample=0.8, reg_lambda=1.0`。
- 组合模拟：现金+持仓逐日 mark-to-market；v4.0：买入=收盘×(1+滑点)(1+佣金)，卖出=成交价×(1-滑点)(1-佣金-印花税)；**v4.0.1：佣金/印花税记 0**；一手 100 股整数化；期末强平。

# 当前结论（v4.0.2 修正后）

1. 组合模拟 highest bug 修正后，**v4.0 报告的全部组合级数字作废**；v3.3 baseline 真实口径 = -16.0%/-39.0%，与 v4.0 报告记载的 +8.4% 相去甚远——"信号 IC ≠ 组合收益"的教训依然成立，但旧归因中的具体数字不再可信。

5. 消融：LightGBM/Logistic 仍为正贡献组件；Adaptive 过滤仍为负贡献；高年化小样本行（<30 笔）依旧视为噪声。
6. 下一步：① T10only 结构滚动窗口/分年度复核；② LightGBM 横截面训练（根治 0.64 vs 0.02 过拟合）；③ 正确口径下重调退出参数（Q 分位/目标系数/冷却期）。

# v3.x 算法原理（保留，构成 v4 因子与基线）

## 1. 形态匹配与样本池

**L1 自身历史**：将最近20日的归一化收益率序列作为形态切片，在标的自身全历史中用欧氏距离+量能距离加权匹配，取Top-K样本。
**L2 同行业** / **L3 同市值层**：辅助样本池（可关），捕捉板块联动与大小盘轮动。
三级样本加权融合，用加权百分位数（P10~P90）生成预测区间（校准系数 1.3/1.4）。

## 2. 量能状态与大盘/板块环境筛选

量能分区（放量/平量/缩量）、大盘过滤（涨跌差>0.8pp剔除）、板块过滤（>1.2pp剔除）、开盘缺口兜底。

## 3. 筹码分布（Volume-at-Price Profile）

逐日演化：成交量按高低价摊分到价格格子、按换手率衰减；输出平均成本、获利盘、90%筹码区间、支撑/压力位。

## 4. 多维综合评分（v3.3 买卖点核心）

MACD/KDJ/RSI6/量价/MA20/筹码/统计预测/ADX 八维打分，≥+2 触发 BUY、≤-2 触发 SELL，冷却 5 根K线。v3.3 消融弹窗：训练75%选型/验证25%只报告，三档（保守/稳健/激进）牛熊分段评分，缓存5日。

## 5. 缓存校验

相邻日涨跌幅超限校验（主板10%、创业/科创20%、北交所30%，留3pp容差），异常触发重拉。

## A1 系统研究报告与算法说明（v2.x 时期）

### A1.1 系统概述

**项目背景**：基于历史形态相似度匹配 + 多维融合的股票短线统计预测工具集，通过三级样本池加权融合、筹码分布分析、多维综合评分买卖点系统，实现股票价格走势的预测。

**系统架构**：
```
数据层 (Data Layer)
├── 腾讯行情接口 (Tencent Quote API)
├── 东方财富 (Eastmoney)
├── 网易163 (Netease)
├── 新浪财经 (Sina Finance)
└── 本地缓存 (SQLite Database)

算法层 (Algorithm Layer)
├── 形态匹配 (Pattern Matching)
├── 量能分析 (Volume Analysis)
├── 筹码分布 (Chip Distribution)
├── 多维评分 (Multi-dimensional Scoring)
└── 样本加权 (Sample Weighting)

应用层 (Application Layer)
├── GUI图形界面 (Graphical Interface)
├── 命令行工具 (Command Line Tool)
└── Web服务 (Web Service)
```

### A1.2 算法原理

**形态相似度计算**（`_pool_match` 核心）：
```python
# 1. 形态距离计算 (欧氏距离)
d_px = sum((a - b) ** 2 for a, b in zip(cur, w)) ** 0.5
# 2. 量能相似度
d_v = abs(math.log(max(vr_now, 1e-6) / max(vr_i, 1e-6)))
s_v = 0.6 * min(d_v, 2.5)
# 3. 大盘环境相似度
s_i = min(1.5, 0.3 * abs(ic - idx_chg_today))
# 4. 总评分 = 形态距离 + 量能项 + 大盘环境项
total_score = d_px + s_v + s_i
```

**三级样本池加权融合**：L1 自身历史 0.6 / L2 同行业 0.3 / L3 同市值层 0.1（v3.x 后期 L3 已删，见 A2）。

**筹码分布计算**（`calc_chips`）：每根K线成交量按高低价区间摊分到价格格子，历史筹码按换手率衰减（`t = min(0.20, max(0.002, 0.02 × vol/med_vol))`），输出平均成本、获利盘比例、90%筹码区间、支撑位/压力位。

**精度提升措施**（v2.x 引入，后续消融部分推翻/修正，以 A2 为准）：
- 候选样本池 10→50 个，按加权质量选最终 TOPK；
- 相似度加权 `weight = 0.5 + norm_sim`（后被证明是头号拖累，A2 §一）；
- 置信度系统（样本数量/相似度一致性/权重分布/层级完整性四因子，≥0.6 高、0.3~0.6 中、<0.3 低）；
- 时间衰减（90天起衰减，最低 0.3；后被证明须保留，A2 §二）。

**性能指标（当时自评）**：形态匹配方向准确率约 55-65%（后被 n=4500 满功率裁决修正为 ≈50%，见 A2 §8.1）；启动 3-5 秒；实时 30 秒刷新。

## A4 波段优化与各类型 IC 评估（2026-09-04）

### 发现并修复的问题

1. **`_bar_ok` 影线规则误杀老数据**：原"影线>实体1.5倍剔除"在低价股老K线误杀率 30%+，且无统计依据。改为仅结构性校验，价格异常由涨跌幅校验兜底。
2. **`load_pools_progressive` 重复累计**：每批样本 `acc_rows +=` 执行两次，样本翻倍污染匹配。已修复。
3. **`daily_picks` 整库载入**：全市场×1000根会占 2GB+ 内存。改为"根数初筛→分块→窗口函数取尾部400根"。
4. **东财增量拉取 `count=900`**：与 1000 根目标不匹配，缓存永远凑不齐。增量上限提到 1100。
